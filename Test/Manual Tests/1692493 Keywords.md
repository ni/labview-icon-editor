The IE provides two keyword fields where users may search for glyphs or icon templates.
In order to fully validate the test steps, make sure that the icon editor has been launched at least once and that the templates and glyphs tab have been populated with data (glyphs) before closing the icon editor.
1. Make sure that the LabVIEW Data folder contains an Icon Template and a Glyphs folder
2. Check if all sub-folders and file names are localized (if the test is processed on a non-engl LabVIEW)
3. Launch the IE and search for different glyphs or icon templates on the icon templates and glyphs page.
4. Right-click on several different glyphs and make sure that the path is updated appropriately at the bottom of the page.
