Run this test on LabVIEW for Windows 2000, XP, Vista, Linux and Mac.

1. Launch the Icon editor as an out of the box product (fresh installation of LabVIEW) from a VI and make sure that it launches properly.
2. Run the icon editor setting dialog, make sure that nothing is screwed up.
3. Launch the 'Synchronization with ni.com/iconlibrary' and make sure that it works properly.
4. Drop several different glyphs, write some text on the icon text tab, press OK and relaunch the IE immediately.
5. Make sure that all layers and the icon text are persistent.
