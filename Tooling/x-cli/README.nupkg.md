# x-cli

Command-line tooling for LabVIEW Icon Editor workflows (upstream in this repo).

## Getting started

- Run `xcli --help` for command list.
- Typical flows: build/verify source distribution, VI Analyzer, VI History replay, telemetry validation.
- See repo docs: `docs/x-cli-playbook.md` and `MAINTAINING-x-cli.md`.

## Versioning

- Semantic versioning; prereleases use suffixes like `-rc.1`.
